# GreatCampus — Assess. Interview. Develop.

**AI-powered talent solutions to identify the right people, make better hiring decisions, and continuously develop talent.**

From assessment to interview to development, GreatCampus helps organizations build a smarter, faster and more measurable talent journey.

---

## 🌟 Core Pillars & Product Suite

1. **01 - ASSESS (`/assess`)**
   - Aptitude Assessments (Numerical, Logical, Verbal, Data Interpretation)
   - Technical Sandbox with support for 15+ coding languages
   - Behavioural & Role-based competency matrices
   - 360° AI-Powered Anti-Cheat Proctoring & webcam integrity monitoring

2. **02 - INTERVIEW (`/interview`)**
   - AI-powered structured first-round voice and video interviews
   - WhatsApp Voice Notes, Direct Automated Phone Calls, and Web Video Room
   - 14 Indian & Global languages with dynamic contextual follow-up questioning
   - Instant ATS candidate scorecards, audio citations, and ranked queues

3. **03 - DEVELOP (`/develop`)**
   - Automated skill gap-to-microlearning mapping
   - 3–5 minute practical daily scenario modules (Sales, Service, Leadership, Operations, Onboarding)
   - Continuous 30/60/90-day reassessment measuring verifiable progress (+28% retention delta)

4. **Lifecycle Solutions (`/solutions`)**
   - For Corporate Talent Acquisition & High-Volume Recruitment
   - For Staffing & Recruitment Agencies
   - For Universities & Higher Education (Employability & Placement Readiness)
   - For Learning & Development (Corporate Capability Building)

## 🚀 Tech Stack

- **Framework**: Next.js (App Router, Turbopack)
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Design System**: Luxury High-Contrast Monochrome (Black & White)
- **Icons**: Lucide Icons
- **Typography**: Plus Jakarta Sans / Inter

---

## 🛠️ Getting Started

First, install dependencies and run the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
